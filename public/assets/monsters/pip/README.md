# PIP production assets

Deliver `base.png`: 256×256, 8-bit non-interlaced RGBA PNG, transparent
background, canvas bottom-center anchor, source RIGHT. No artwork is supplied.
The independent monster registry resolves this directory. Future animation files
may use `idle/`, `walk/`, `hit/`, `attack/`, `defeat/`, `capture/`; no monster
animation loader/controller or clip contract is implemented in this milestone.
